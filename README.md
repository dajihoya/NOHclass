# 노글라쓰의 업무자료실

학급 운영과 수업 도구를 한 화면에서 여는 선생님용 첫 화면입니다.

- `index.html` — 첫 화면 (아이보리 옥스포드 노트 배경, 코르크 메모판 제목, 수업 자료(누르면 수업페이지) 아래 칠판 속 생명과학·지구과학, 학급 운영)
- `seats.html` — 학급 자리 뽑기 (5×6, 30자리 무작위 배치)
- `cleaning.html` — 학급 청소 당번 뽑기 (면제·고정 역할 지정 후 구역별 배정)

수업 칸은 학생용 과학 사이트 Science Class by Teacher 노글라쓰([dajihoya/scienceclass](https://github.com/dajihoya/scienceclass), 주소 dajihoya.github.io/scienceclass)의 시뮬레이션으로 연결합니다. 학생용 사이트에는 학급 운영 메뉴가 보이지 않습니다.

학생 이름은 페이지에 저장되지 않습니다. 쓸 때마다 입력하거나 엑셀 파일로 불러옵니다.
